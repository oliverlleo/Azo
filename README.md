# AZO — site premium

Reconstrução completa da experiência visual e de motion design.

## Abrir
Extraia o ZIP e abra `index.html` diretamente no navegador. Os caminhos são relativos e não exigem servidor para a prévia.

## Motion
- Fundo arquitetônico animado em Canvas, leve e adaptativo.
- Loader / entrada da marca.
- Hero com cenas automáticas, wipe/máscara e zoom de câmera.
- Tipografia de abertura sequenciada.
- Serviços com transição autônoma e também clique/toque.
- Diagrama de integração com desenho de planta em loop.
- Portfólio com showcase automático, controles e galeria.
- Transições entre páginas e microinterações.
- Mobile mantém motion, com densidade reduzida para preservar fluidez.
- `prefers-reduced-motion` respeitado.

## Conteúdo/arquitetura
Home, Serviços, Projeto Arquitetônico, Interiores, Gestão de Obras, Projetos, Sobre e Contato.
